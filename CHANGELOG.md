# Changelog

## v0.1.0 (Coming Soon)

### Added
- Core pipeline: read, extract, chunk, embed, store, retrieve
- Pluggable architecture: 20+ Base* abstract classes
- Format support: PDF, DOCX, images, Excel, CSV, JSON, XML, databases
- Extraction engine: text, tables, fields, forms, entities, images, layout
- Strategy router: rule-based, deterministic (fast/ocr/api/structured paths)
- Speed engine: multiprocessing, GPU workers, threading, async I/O
- Incremental processing: hash-based change detection, sync cursors
- Correction store: exact user overrides, no ML, deterministic
- RAG: structure-preserving chunking, hybrid search, Q&A
- GraphRAG: document graph, community detection, graph-enhanced retrieval
- Pipeline DAG: composable nodes, YAML config, parallel execution
- Agentic pipeline: DocumentAgent, multi-agent composition
- Connectors: 15+ vector stores, 7+ databases, cloud storage
- Templates: invoice, contract, resume, receipt + more
- CLI: ingest, extract, query, ask, serve, mcp
- REST API server (FastAPI)
- MCP server mode
- Docker + Docker Compose
- Ecosystem bridges: SightRAG, sonarwise, adaptive-intelligence, llmevalkit
